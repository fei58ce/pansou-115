# 温柔线描 UI 精修设计规格

## 背景

项目已经完成一版温柔线描视觉改版，但仍有少量页面级细节没有完全遵循该风格的可用性要求：移动端部分点击元素使用了非交互标签、用户关闭动效偏好时仍会运行骨架与路由动画，主按钮文字颜色还存在裸色值。此次精修沿用现有组件和插画，不改变接口、导航或业务流程。

## 目标

1. 保持温柔线描的视觉基准：暖白背景、暖棕细线、鼠尾草绿主色、灰粉选中态、轻量手绘圆角。
2. 让移动端最近搜索、刷新和退出登录等操作具备原生键盘/辅助技术语义。
3. 尊重 `prefers-reduced-motion`，关闭用户不需要的路由淡入和骨架闪烁。
4. 用设计令牌替代按钮文字的裸色值，避免主题切换或组件覆写时出现不一致。

## 非目标

- 不新增搜索源、账号、下载或订阅能力。
- 不替换已经确认的插画素材，不改变页面信息架构。
- 不迁移 Element Plus / Vant，不做与本次视觉质量无关的依赖升级。

## 方案

### 令牌

在 `tokens.scss` 增加 `--primary-foreground`，作为鼠尾草绿实色按钮上的文字颜色，默认使用暖白表面色。搜索按钮改用该令牌。

### 交互语义

- 移动端首页头像改为带 `aria-label` 的原生 `button`，保留现有点击退出流程。
- 移动端资源页的“最近搜索”“清空”“刷新频道最新资源”和刷新图标改为 `button`，保留现有事件与视觉。
- 给图标按钮补充可见焦点样式，确保键盘操作可辨认。

### 动效

在应用级样式中加入 `prefers-reduced-motion: reduce` 覆盖：路由淡入淡出与骨架 shimmer 不再播放，保留内容的即时呈现。

## 验收

- `npm run build:frontend` 通过。
- 前端测试通过。
- 1440×960 与 390×844 预览无横向溢出，关键操作仍可点击。
- 使用浏览器检查移动端按钮的 `role`、`aria-label`、焦点状态和 reduced-motion 样式。

## 回退

本次改动只涉及前端令牌、模板语义和样式。回退对应提交即可，不触碰生产配置、数据库和后端接口。
