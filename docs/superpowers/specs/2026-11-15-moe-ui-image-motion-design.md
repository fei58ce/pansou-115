# 温柔线描图片动效设计规格

## 背景

上一版已经完成温柔线描插画视觉，但插画素材仍是静态 WebP。用户反馈页面缺少图片动画风格。本次只增强素材的运动表现，不改变插画文件、业务逻辑和页面结构。

## 设计方向

- **轻漂浮**：登录页场景、侧栏人物、搜索栏探头和空状态插画缓慢上下移动并轻微旋转。
- **轻呼吸**：Logo 与移动端头像做极小幅度缩放，保持线稿稳定、不产生跳动感。
- **同一节奏**：漂浮约 6 秒一轮，呼吸约 5 秒一轮，避免多个素材同时快速变化。
- **可访问性**：尊重 `prefers-reduced-motion: reduce`，关闭全部动画。

## 实现边界

使用现有 WebP 素材和 CSS keyframes，使用 CSS 独立 `translate`/`rotate`/`scale` 属性保留组件原有定位变换。不引入 GIF、视频、Lottie 或新的网络依赖。

## 验收

- 桌面登录页至少有两个漂浮素材，移动登录页有漂浮场景和呼吸 Logo。
- 浏览器计算样式包含 `moe-line-float` / `moe-line-breathe`，同一元素在两个时间点的坐标有可见变化。
- `prefers-reduced-motion` 下动画名为 `none`。
- 1440×960 与 390×844 无布局位移、横向溢出或功能回归。
